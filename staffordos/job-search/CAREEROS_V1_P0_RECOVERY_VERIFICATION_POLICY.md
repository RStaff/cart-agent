# Recovery and Verification Policy

For the first controlled invite-only text beta, accounts are created only from a single-use invitation bound to the normalized email. Email verification and automated recovery are deferred because no authorized mail provider exists.

Before public beta, add verified email ownership and one-time, expiring, hashed reset tokens with rate-limited delivery. Until then, a lost account is an operator-supported exception using an audited reset procedure; no direct password database edits are permitted.
