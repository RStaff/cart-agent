# CareerOS V1.25C MVP Source Strategy

## Recommendation

Launch the MVP as a **multi-mode analysis product**, not a universal crawler:

1. existing Greenhouse direct-source lane;
2. user-pasted URL, saved posting, or job-description input;
3. CareerOS requirement/provenance/evidence/preference analysis;
4. optional licensed aggregator only after a written commercial contract.

This delivers product value without making broad discovery rights a prerequisite. It also lets CareerOS validate willingness to pay around evidence-grounded analysis before taking on data supply cost.

The first commercial data conversation should be Adzuna or TheirStack. USAJOBS is a safe narrow supplement, not a general-market answer.
