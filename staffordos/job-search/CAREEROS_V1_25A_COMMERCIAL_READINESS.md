# Ashby Commercial Readiness

**Classification: `ASHBY_PARTNER_PERMISSION_REQUIRED`.**

Technical suitability is promising, but the public documentation does not establish permission for CareerOS's proposed cross-employer commercial discovery use. The endpoint's documented own-careers-page use case is narrower than this product mission.

Productionizing would require:

1. written Ashby or employer authorization for the exact use case;
2. approved board scope and rate limits;
3. retention/display/reuse terms for descriptions and HTML;
4. closure and freshness semantics;
5. a bounded pilot with real payload round-trip proof;
6. cross-provider dedup acceptance;
7. provider-neutral regression proof.

No production readiness claim is made.
