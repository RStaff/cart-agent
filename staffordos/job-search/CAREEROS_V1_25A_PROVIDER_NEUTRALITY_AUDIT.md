# Provider Neutrality Audit

The existing normalization boundary is provider-neutral: Greenhouse already maps into `RawJobSourceInput` and `NormalizedJobSourceRecord`, including raw content and `sourceStructure`.

Ashby was not implemented because authorization was insufficient. The planned adapter has no downstream Ashby branch. Acceptance must prove the same requirement extraction, provenance, evidence-linkage, qualification, preference, and offline V2D diagnostics consume both providers by canonical fields only.

Greenhouse regression result: no Greenhouse source or consumer was changed in V1.25A.
