# CareerOS V1.25C Long-Term Source Strategy

Recommended target architecture: **hybrid**.

```text
licensed aggregator discovery
        + direct ATS authoritative enrichment
        + user-supplied opportunities
        -> canonical opportunity observations
        -> deduplication and freshness authority
        -> source-aware requirement provenance
        -> CareerOS analysis
```

Use Adzuna/TheirStack for breadth only under contract. Use Greenhouse, Lever, SmartRecruiters, Ashby, and Workday only when employer/partner authority exists. Use Lightcast for structured labor-market enrichment rather than assuming it is a raw posting replacement.

Keep every provider optional so the product can retire a source without invalidating CareerOS-derived analysis or user review history.
