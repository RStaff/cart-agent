# CareerOS V1.25C Provider Authority Report

## Explicitly Commercially Oriented

- **Adzuna:** API permits publishing listings; broader commercial use is limited to a 14-day validation trial unless written consent/license is obtained. It also imposes attribution and removal requirements.
- **TheirStack:** Paid API and datasets are explicitly designed to supply real-time/historical job data across 100+ countries; contract terms still govern retention and display.
- **Lightcast:** Licensed Global Job Postings API is explicitly designed for labor-market analysis, recruitment intelligence, research, automation, and integration.
- **USAJOBS:** API documentation explicitly anticipates commercial job boards, mobile applications, and social-media employment venues, subject to API terms/key.

## Explicitly Scoped/Restricted

- **The Muse:** API license supports Apps displaying Muse Content with link-back, but prohibits cloning, sublicensing, and web extraction; derived commercial analysis needs written confirmation.
- **LinkedIn:** Vetted Job Posting API only; approved applications and authorized clients, narrow storage/use, and deletion obligations.
- **ATS sources:** Greenhouse, Lever, SmartRecruiters, Workday, and Ashby are employer/tenant or partner surfaces, not automatically cross-employer commercial datasets.

## Not Safe as Default Discovery

Indeed, Built In, Wellfound, Google job-search surfaces, and generic RapidAPI wrappers do not provide a sufficiently clear commercial source license for this product without specific agreements.

This is an access/architecture audit, not legal advice.
