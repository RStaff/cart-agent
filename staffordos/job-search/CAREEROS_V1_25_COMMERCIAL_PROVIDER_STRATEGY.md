# CareerOS V1.25 Commercial Provider Strategy

## Greenhouse Only

Credible source fidelity and maintainability, but coverage is limited to employers using Greenhouse and to boards explicitly configured in the manifest. It is a good quality-first foundation, not broad market coverage.

## Recommended Commercial Path

1. Keep Greenhouse as the reference-quality direct source.
2. Add Ashby only through a bounded, terms-reviewed pilot because its official public job-board API exposes HTML/plain text, locations, work arrangement, employment type, dates, URLs, and optional compensation.
3. Add Lever through customer-authorized Posting API/XML feed agreements.
4. Add SmartRecruiters through customer-authorized Posting API or Job Board partner agreements.
5. Add Workday only per-tenant when a customer authorizes the integration.
6. Treat Indeed, Built In, and Wellfound as partnership/business-development tracks, not scraping targets.

## Product Position

The commercially credible differentiator is source-authoritative, structure-preserving, deduplicated job intelligence. A smaller set of direct/authorized ATS sources is preferable to a larger aggregator corpus with uncertain reuse rights, stale status, and flattened descriptions.
