# CareerOS V1.26A Customer Evidence Onboarding Design

## Provider-neutral flow

`SOURCE -> FACT CANDIDATE -> EVIDENCE CANDIDATE -> CUSTOMER VERIFICATION -> CANONICAL CAREER EVIDENCE -> MATCHING`

## Minimum viable onboarding

1. Import a resume or career-history export privately.
2. Add at least one authoritative employment/history source.
3. Add project/portfolio/GitHub artifacts for technical claims.
4. Add official certification/education records where relevant.
5. Review extracted facts and conflicts.
6. Confirm bounded transferable statements separately from direct claims.
7. Generate matching diagnostics only from eligible evidence.

Resume-only customers can receive `UNKNOWN`, `TRANSFERABLE`, and evidence-gap diagnostics, but not fabricated capability claims. Operator confirmation must remain visibly distinct from independent source evidence.
