# SmartRecruiters Commercial Authority

SmartRecruiters documents a Posting API for customers building custom career sites and a Job Board API for partners. The Posting API can list active public postings by company and supports company-scoped querying; the platform documents API-key/customer and partner authentication paths.

Conclusion: `PARTNER_PROGRAM_REQUIRED` for CareerOS cross-employer commercial discovery. The API is technically promising but its documentation describes customer career sites and partner widgets, not a blanket license for an unrelated paid job-analysis marketplace. A future pilot needs written SmartRecruiters or participating-customer authorization covering retention, display/linking, derived analysis, rate limits, and removal.
