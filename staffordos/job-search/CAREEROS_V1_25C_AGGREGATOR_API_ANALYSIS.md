# CareerOS V1.25C Aggregator API Analysis

## Adzuna

Best near-term commercial call. Its API searches a full listings database and its terms explicitly define publishing use, trial use, limits, attribution, termination cleanup, and written-consent requirements for ongoing commercial uses. The default limits are 25 hits/minute, 250/day, 1,000/week, and 2,500/month; increased limits require contact. Full details, standardized titles/skills, and historical data are product-dependent.

## TheirStack

Best API-shaped discovery candidate. Official docs describe real-time and historical jobs across 100+ countries, paid API access, datasets, pagination, webhooks, and rate-limit headers. The major contract questions are raw description/HTML retention, display rights, attribution, and derived-analysis rights.

## Lightcast

Best high-authority analytics/enrichment candidate. Its Global Job Postings API requires OAuth and a licensed scope, supports active/date filtering and structured taxonomies, and is designed for analysis, automation, and integration. It may not provide the raw employer HTML needed for CareerOS provenance, so it should enrich rather than replace direct ATS source authority.

## Jooble

Potential partner source. Its REST API returns IDs, title, company, link, location, type, salary, updated time, and snippets. The publisher/partner ecosystem is real, but commercial retention and derived-analysis rights require a partner agreement.

## JSearch/RapidAPI

Not a source authority. RapidAPI supplies marketplace billing and quotas, but the upstream provider's acquisition, retention, and redistribution rights remain separate and must be verified per API. Do not make it the primary source.

## The Muse

Useful curated supplement, not a raw-data warehouse. It has a public registered-app API, hourly limits, pagination, and link-back requirements, but its terms prohibit cloning, sublicensing, and web extraction and grant only a revocable limited API license.
