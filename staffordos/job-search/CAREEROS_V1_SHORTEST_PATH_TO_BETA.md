# CareerOS V1 Shortest Path to Beta

## First external user

1. P0: choose/adapt account and session boundary, including recovery and tenant authorization. (M)
2. P0: add tenant-scoped CareerProfile, source, fact, evidence, capability decision, and version tables. (L)
3. P0: add private document storage references, export, deletion, and audit events. (M)
4. P0: adapt A3 graph/projection as an internal tenant-scoped service. (M)
5. P0: implement resume/manual intake and neutral 5-15 question review. (L)
6. P0: implement pasted job/URL intake and explainable match view. (M)
7. P0: add failure handling and tenant-scoped background jobs. (M)

## Five-user private beta

Add consent, support read-only access, telemetry, correction flows, rate limits, and a customer-neutral validation harness. (M)

## Ten-user beta

Add retention operations, entitlement boundaries, source freshness, incident runbook, and broader role-family test coverage. (M)

## Public/free beta

Require security review, deletion/export verification, operational monitoring, clear source licensing, customer terms, abuse controls, and measured onboarding results. Provider expansion is optional and separate.

No precise calendar estimate is claimed.
