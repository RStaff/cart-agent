# CareerOS V1.26C Decision Leverage Model

This is operator-review prioritization, not Match Engine ranking.

`priority = candidate_count * 4 + unresolved_verification_count * 3 + linked_source_count * 2 + program_accountability_bonus`

The model favors questions that cover recurring candidates, can resolve reusable capability ambiguity, preserve provenance, and distinguish scope/technical-depth claims. It excludes self-confidence, interest, would-pursue, workflow, aspiration, title prestige, and job ranking.

The first queue contains 16 clusters, below the 18-question bounded capacity. No arbitrary role-specific boost is used. The cluster contract prevents propagation across specialist/generic boundaries and incompatible direct/transferable states.
