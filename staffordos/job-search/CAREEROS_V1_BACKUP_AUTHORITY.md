# CareerOS Backup Authority

Backup authority is not currently proven for a CareerOS target. The existing Render backup evidence belongs to shared/other-product infrastructure and cannot close this gap.

Before accepting customer data, the selected managed PostgreSQL provider must document encrypted automated backups, retention, access control, restore to an isolated target, and an operator-owned restore test. The minimum beta policy is a recent provider snapshot plus a tested restore procedure before the first invite.

This mission did not create a database, snapshot, restore point, or backup policy.
