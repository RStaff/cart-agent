# CareerOS V1.25 Source Authority Priority

## Priority Order

1. Employer-controlled ATS/API observation with explicit public posting state.
2. Employer-controlled career page backed by a documented ATS feed.
3. Authorized job-board partner feed with explicit publication state.
4. Authorized aggregator API with documented reuse rights.
5. Public aggregator page only after written terms/access approval.

This order reflects proximity to the employer's source of truth, ability to observe closure/freshness, structured-content fidelity, and lower republication ambiguity. It is not a claim that a lower-priority source is inaccurate in every case.

## Conflict Rules

- Direct ATS identity outranks aggregator identity when the duplicate match is confirmed.
- A direct source can supersede title/location/description display, but the aggregator observation remains provenance.
- Aggregator-only observations must not prove that a job is open when the direct source says closed.
- Conflicting observations remain visible to diagnostics and may require operator review.
- Source priority does not change capability fit or human labels.
