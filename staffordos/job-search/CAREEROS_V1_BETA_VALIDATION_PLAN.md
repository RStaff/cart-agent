# CareerOS V1 Beta Validation Plan

Run a private beta with 5-10 users across different seniorities, industries, and role families. Do not use their data in committed artifacts.

Measure per user: onboarding completion, questions required, time to profile, capability count, requirements informed, DIRECT/TRANSFERABLE/PARTIAL distribution, unknown rate, specialist leakage, scope violations, correction rate, match explanation usefulness, and return-session completion.

Acceptance gates: tenant isolation tests pass; deletion/export works; no cross-user reads; specialist leakage 0; scope violations 0; all positive relationships trace to customer authority; no outcome/workflow/self-confidence leakage; median question burden reported rather than assumed.

Evaluation is diagnostic and customer-consented. Application outcomes may inform pursuit priority experiments only; they do not rewrite capability truth.
