# CareerOS V1.25D Adzuna Comparison

Adzuna remains a possible fallback, but not an automatic next implementation.

Adzuna's official developer terms state that commercial organizational use beyond the validation trial requires written consent/license, with attribution and deletion/removal obligations. That makes its authority explicit only after written approval. TheirStack has clearer self-serve API pricing and explicit partial platform resale/job-display language, but also a material non-compete boundary and third-party-rights disclaimer.

| Dimension | TheirStack | Adzuna |
| --- | --- | --- |
| Commercial authority | Supported with product boundaries; confirm intended SaaS workflow | Written commercial consent/license required beyond trial |
| API cost | Public API tiers, 1 credit/job | Public developer limits; commercial pricing/permission must be confirmed |
| Breadth | Broad multi-source job database | Broad aggregator/search API |
| Description/source fidelity | API job records and original source fields documented; verify in pilot | Varies by source; verify description and original URL in authorized pilot |
| Retention/display | Partial extracts/job postings permitted subject to terms | Attribution/deletion and license terms are central |
| Recommendation | First authority conversation after credential setup | Fallback/parallel commercial inquiry |

Source: [Adzuna developer terms](https://developer.adzuna.com/docs/terms_of_service).
