# CareerOS Capability Onboarding

Confirmed tenant CareerFacts are the only input to capability proposals. Proposals retain fact and source provenance, then a short customer review records an append-only decision. The global taxonomy remains separate from tenant authority. Job input is user supplied and is evaluated against the tenant capability authority using frozen direct, transferable, partial, unknown, specialist, and scope semantics.

The first product path is profile, source, fact review, capability review, capability profile, pasted job, and explanation. No requirement-level review loop is used.
